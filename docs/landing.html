01拆得开

识别交付物、约束、领域、主 / 次意图、子任务与假设；把「录音 → 纪要 + 宣传片」拆成两业务线。规则引擎，结果带置信度和 assumptions，不是黑箱。

02组得拢

2–5 个技能按阶段组队，标出交接物、冲突、回退与缺口；没有合适技能时明确说「缺」，不硬凑。

03造得出

按缺口生成 SKILL.md 草稿：frontmatter、步骤、I/O、质量检查、eval cases、lint、安全扫描。不写盘、不执行，确认后你自己保存。

边界先说清：推荐 / 检索是本地启发式，不是神经模型；decompose / compose 是规则引擎，不是 LLM；效率默认是 estimate。每条声明的证据与未实测项在 docs/claims.md。

3 分钟 demo：plan → compose → draft

真实任务：「把这段会议录音整理成可交付的会议纪要 docx，再做一个 30 秒宣传片。」跨 Office + 视频，多意图，带缺口。 A real multi-intent task: meeting recording → deliverable minutes.docx + a 30-second teaser.

plan：拆任务

用 skill_archive_plan 拆解这个任务，先不要执行：…
  • 主意图 Office / 次意图视频
  • 交付物：minutes.docx、teaser.mp4
  • 约束：30 秒、9:16、时间戳引用
  • 缺口：会议纪要模板 → draftNeeded
  • 不执行、不装技能、不写盘

compose：组队

用 skill_archive_compose 给任务组队：2–5 个技能，标出顺序、交接、缺口和冲突。
  • office-docx → 纪要文稿
  • office-render → 版式校验
  • beat-promo-director → 30 秒分镜
  • media-use → 素材与配乐
  • sequential + review-gate；缺口进 draft

draft：造技能

用 skill_archive_draft_skill 补「会议纪要模板」，只给草稿、不要落盘。
  • SKILL.md 草稿 + whenToUse
  • 3–5 条 eval cases
  • lint + 安全扫描结果
  • 不写盘、不执行
  • 你确认后自己保存到 ~/.dsh/skills/

示意输出，字段以 v5.0.0 实际版本为准。三个工具都是只读 / 只出草稿，没有 install / force / 执行能力。

效率怎么谈：estimate 与 benchmark 分开

我们不在 README 里写「效率提升 X%」。估算（estimate）用于规划，实测（benchmark）必须有脚本、有基线、有原始数据。 Estimates are for planning; measured numbers require a reproducible benchmark. We do not publish percentages before the benchmark exists.

安装（v5.0.0 发布后）

在任意 DeepSeek Harness 会话里让 Agent 执行；profile 级安装，需要 danger-full-access 或审批。发布前请用本地目录方式。Install in any DSH session; before v5.0.0 is tagged, use the local-path method.

npx dsh-ronge-adaptive-skill-archive

安装后

刷新页面 → 右上角「技能」→ 右侧抽屉；顶部切换计划 / 沉浸模式。DSH 重启后加载新的 Host 模块。

安全说明：把边界写在前面

这是一个本地优先的个人工具，不是托管服务，也不是安全产品。Local-first by design, not a hosted service and not a security product.

本地零遥测

推荐、拆解、组队、草稿、扫描、自进化全部在本机完成；不调用外部模型、不上传、无遥测。只读当前会话最近内容与项目文件名。

诚实扫描不是保证

安装前安全扫描是启发式：能发现 shell 执行、管道下载、动态解码、提示注入、凭据路径、过宽 allowed-tools 等模式，但覆盖不了全部攻击面。不宣称「无漏洞」。

克制不越权

只从 raw.githubusercontent.com 拉 SKILL.md（≤ 256 KiB），不自动拉脚本、不覆盖已有技能；高风险默认拒绝；draft 不写盘、不执行；DSH 工具没有 install / force。
