# Data notice

This directory contains a metadata index of publicly indexed GitHub `SKILL.md` files:
name, description excerpt, whenToUse, category, rating, repository and path.

- The index stores metadata only; it does not redistribute skill instruction bodies.
- Each skill remains under its own repository's license; check the source repository before using it.
- Descriptions are short excerpts used for search/preview; rights remain with their authors.
- To request removal of an entry, open an issue in this repository.
